# LiveGraph paper

ACL-style 4-page system-demonstration paper. Numbers come from `docs/results/` (generated by
`python -m lgeval report`); nothing in `main.tex` is hand-copied from results except prose summaries,
which are marked `\todo{}` until the study is run.

## Build
1. Drop the ACL style files into this directory from
   [github.com/acl-org/acl-style-files](https://github.com/acl-org/acl-style-files)
   (`acl.sty` and `acl_natbib.bst`; they are not vendored here).
2. Generate the results: `cd apps/api && uv run python -m lgeval report --results ../../eval-results --out ../../docs/results`.
   Every table in `docs/results/tables/*.tex` is written even without data (a "Results pending" placeholder),
   so the paper always compiles.
3. Convert the SVG figures to PDF (LaTeX cannot include SVG directly), e.g. with
   `rsvg-convert -f pdf -o x.pdf x.svg` (librsvg) or `inkscape x.svg --export-filename=x.pdf`:
   ```bash
   for f in ../results/figures/*.svg; do rsvg-convert -f pdf -o "${f%.svg}.pdf" "$f"; done
   ```
   Missing PDFs render as a "Figure pending" box.
4. `latexmk -pdf main.tex` (or `pdflatex main && bibtex main && pdflatex main && pdflatex main`).

For the camera-ready version change `\usepackage[review]{acl}` to `\usepackage[final]{acl}` and fill in
the authors. Re-check every `refs.bib` entry against the ACL Anthology / publisher page before submission.

## Files
- `main.tex`: the paper. `\resulttable{name}` inputs `../results/tables/name.tex`; `\resultfig{name}{width}`
  includes `../results/figures/name.pdf`.
- `refs.bib`: verified references only; uncertain ones are left as `% TODO` comments.
- `blog.md`: blog post outline, arXiv checklist and venue list.
