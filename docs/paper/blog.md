## Outline

1. **Hook (1 paragraph).** You ask a deep-research agent a question, get a 3-page report, and notice that one
   number comes from a dubious blog. Your options: live with it, or re-prompt and pay for and wait through the
   whole run again, hoping the other 95% stays the same.
2. **The idea.** Treat the report like a build. A planner draws the research workflow as a graph you can see;
   each step is a versioned node keyed by a hash of its inputs. Change one input and only what depends on it
   recomputes, and the recompute stops as soon as an output comes back unchanged (early cutoff, borrowed from
   build systems).
3. **What it looks like.** GIF: goal typed → graph appears → nodes stream → claims panel with confidence bars →
   distrust a source → three nodes go stale and recompute → brief updates. (Record with the demo script.)
4. **Debate for confidence.** Prosecutor vs. defender per claim; the judge assigns a confidence or strikes it.
   - Calibration: Brier `{{calibration.full.brier}}`, ECE `{{calibration.full.ece}}`, AUROC
     `{{calibration.full.auroc}}` over `{{calibration.full.n}}` labelled claims; struck claims were false
     `{{calibration.full.struck_false_rate}}` of the time. Embed `figures/reliability.svg`.
5. **Does the graph make better briefs?**
   - Factual precision: full `{{quality.full.factual_precision.mean}}`
     [`{{quality.full.factual_precision.ci_low}}`, `{{quality.full.factual_precision.ci_high}}`] vs. single agent
     `{{quality.single_agent.factual_precision.mean}}`.
   - Citation precision / recall: `{{quality.full.citation_precision.mean}}` / `{{quality.full.citation_recall.mean}}`.
   - Pairwise: full preferred over no_debate `{{pairwise.no_debate.win_rate}}` of the time.
   - Embed `figures/quality.svg`. Be candid about ablations that made no difference.
6. **What a change costs.**
   - Distrust a source: `{{recompute.distrust.cost_pct.mean}}`% of the cost of starting over,
     `{{recompute.distrust.time_pct.mean}}`% of the time; `{{recompute.distrust.nodes_reused}}` nodes reused.
   - Steer a node: `{{recompute.steer.cost_pct.mean}}`%. Identical rerun: `{{recompute.identical.cost_pct.mean}}`%.
   - Embed `figures/recompute_cost.svg`.
7. **How we measured (short).** Link `docs/EVAL.md`: pre-registered protocol, cross-family judge, position swap,
   human spot-check (κ), 95% bootstrap CIs, three repeats. The whole study cost `{{study_cost.total_usd}}` USD.
8. **Limitations.** LLM judges, small n, web drift, exact-hash cutoff misses rewordings.
9. **Try it.** Repo link, `make dev`, mock UI (`npm run dev:mock`), paper link (arXiv), reproduce with `lgeval`.

## arXiv submission checklist

- [ ] Primary category **cs.CL**; cross-list **cs.AI** and **cs.HC**.
- [ ] Endorsement: first-time submitters to cs.CL may need an endorsement from an established arXiv author in
      that category; request it early (arXiv's endorsement page explains the process).
- [ ] License: choose before submitting (cannot be made more restrictive later). CC BY 4.0 is a common choice
      for open research; the arXiv non-exclusive license is the default minimum.
- [ ] Compile with the `final` ACL option and real author names (or keep `review` if the venue requires
      anonymity and the venue allows preprints; check its anonymity policy first).
- [ ] Include `refs.bib`-generated `.bbl`, figure PDFs and table `.tex` files in the source upload;
      remove `\todo` macros; check that it compiles with arXiv's TeX Live.
- [ ] Title, abstract (≤1,920 characters), comments field ("4 pages + references; code at <url>").
- [ ] Link code + released `eval-results` archive; add the arXiv id to the README.

## Venues (check current deadlines; dates move every year)

- **ACL / EMNLP / NAACL System Demonstrations tracks** (best fit: 4-page demo papers with a video and live demo).
- **NeurIPS / ICLR / ICML workshops** on LLM agents, tool use, or human-AI collaboration (workshop lists are
  announced a few months before each conference).
- **CHI** (full paper or Late-Breaking Work) or **UIST** (demo / paper) if the user study (Claim D) grows
  beyond a formative study.
- Before targeting any venue, check its call for papers for page limits, anonymity/preprint policy and
  whether a demo video is required.
